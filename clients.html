🛠️ 2. Clash Verge Rev (Windows/Mac) 零基础 3 步上手教程

Clash Verge Rev 是当前替代已停更 Clash for Windows 最完美的现代化客户端。只需 3 步，1 分钟即可畅快畅游全球网络：

1

下载安装并切换至中文界面

访问官方发布页下载安装包（Windows 下载 Clash.Verge_x.x.x_x64-setup.exe，Mac 根据芯片下载对应 .dmg 安装）。安装完成后打开，点击左侧齿轮【设置 (Settings)】，将【语言 (Language)】选择为【简体中文】。

2

导入机场订阅链接并保存

登录你的机场控制台（如隐形人），复制你的专属 Clash 订阅地址。在 Clash Verge Rev 中点击左侧【订阅】，在上方输入框粘贴订阅 URL，点击【保存/导入】。稍等几秒，订阅配置成功下载，右键该配置选择【使用】。

3

选择节点并开启【系统代理】

点击左侧【代理】，选择延迟较低的专线节点（如“香港 IEPL 01”或“日本 01”）；然后回到【设置】或在主界面右上角，将【系统代理】开关打开（开关变为蓝色高亮）。此时打开 Google 或 YouTube 即可秒开！

🚀 3. iOS 苹果用户：Shadowrocket (小火箭) 免翻墙安装与配置

由于众所周知的原因，中国大陆区 App Store 无法直接搜索到 Shadowrocket。苹果用户按照以下指南操作，无需越狱即可轻松搞定：

1

获取一个海外（美区/港区）Apple ID

方案 A（最省心）：在淘宝或发卡平台搜索购买一个已购小火箭的独享海外 Apple ID（通常 5-10 元），包含应用授权；
方案 B（自建）：用电脑访问 appleid.apple.com，国家选美国，账单地址填写免税州（如俄勒冈州 Oregon），无需绑定信用卡即可成功注册。

2

仅在 App Store 登录海外账号（切勿登录手机 iCloud！）

打开 iPhone 桌面上的【App Store】应用，点击右上角个人头像，滑动到最下方点击【退出登录】；然后登录海外 Apple ID。⚠️ 千万不要在手机系统【设置 - iCloud】中登录别人的账号，防止手机被锁死！

3

下载 Shadowrocket 并一键扫码导入

App Store 搜索并下载正版 Shadowrocket（图标为白色底黑色小飞机）。下载后打开手机相机或小火箭右上角【扫描】按钮，直接扫描机场网站上的“导入小火箭二维码”即可自动导入所有节点。点击开启顶部的总开关即可畅连。

🧠 4. 搞懂三大代理模式：告别“国内微信打不开 / 流量偷跑”

很多新手刚接触翻墙客户端时，常常反馈“开了翻墙后淘宝很慢”、“微信发不出图片”或者“几个 G 流量一下子用完了”。这 99% 是因为模式选错了：

✅ 规则分流模式 (Rule) · 99% 用户推荐

原理：客户端内置智能分流列表。访问百度、微信、淘宝、B站等国内站点自动直连，不消耗机场流量；访问 Google、YouTube、ChatGPT 自动走海外专线。速度最快，完全不影响国内 App 使用！

⚠️ 全局代理模式 (Global) · 仅特殊测试使用

原理：手机或电脑上的所有网络请求强制全走海外节点。会导致微信定位在国外、淘宝被验证风控，并且看国内爱奇艺等也会白白消耗昂贵的翻墙专线流量。

💡 TUN 虚拟网卡模式 (增强模式) · 游戏必备

原理：接管整台操作系统的网络层。对于不遵循系统代理的软件（如 Git 命令行终端、Steam 游戏、Telegram 桌面端、安卓模拟器），开启 TUN 模式即可实现全盘无缝代理。

❓ 5. 常见新手报错与应急自查清单

Q1: 导入订阅提示 Fetch Error / 403 / 证书错误？

解答：通常是旧订阅链接被云服务商拦截。登录机场控制台，重新生成最新的订阅链接；或者临时关闭电脑上的杀毒软件，检查网络是否连接正常。

Q2: 节点全部测试延迟都是“超时”或“红字”？

解答：① 检查电脑系统时间是否准确（时间差超过 1 分钟会导致 TLS 证书握手失败，校准电脑时间后即刻恢复）；② 检查套餐是否已到期或流量已用完。

Q3: 为什么打开了代理，ChatGPT 仍然提示 "Access Denied"？

解答：OpenAI 对公网广播 IP 实施严格风控。换用原生机房托管节点（如隐形人机场标记为 GPT/AI 原生解锁的美国或新加坡节点），并开启浏览器的无痕模式即可顺利进入。
